SMS notifications

Optional provider

SMS requires a live provider account and should only be enabled for recipients who have opted in. Provider credentials are read from the server environment so they survive Render deploys and are not stored in the database.

Set TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN and TWILIO_PHONE_NUMBER in Render. Use E.164 numbers such as +919876543210 for parent phones.
